1. 概述

DeepCalm AI 是一个基于多模型路由的心理健康 AI 系统，通过 OpenRouter 聚合网关调用 8 个业界领先的 LLM 模型，为全球用户提供 7 语言（中/英/马来/日/韩/泰/西）的心理健康支持服务。系统核心遵循 CBT-I（失眠认知行为疗法）、正念减压（MBSR）、积极心理学等循证框架，所有 AI 输出均经过安全性过滤（自杀检测/危机检测/敏感内容过滤）。

3.2 用户反馈闭环

  1. 输入: 用户提交对话/签到 → API 接收
  2. 处理: 模型生成回复 → 安全过滤（自杀/危机/敏感内容）
  3. 评估: 可选多模型对比评估（7 维度评分）
  4. 存储: 匿名对话日志落盘 → 用于后续分析优化
  5. 反馈: 用户可通过签到情绪变化间接影响后续交互

3.3 模型路由逻辑

系统默认使用 GPT-4o-mini。当 API 调用失败时，按以下顺序降级：

gpt-4o-mini → deepseek-chat → claude-3.5-haiku → gemini-2.0-flash → gpt-4o → claude-sonnet-4 → fallback (mock)

兜底策略: 所有模型不可用时，启用本地 mockCounselor.ts 模板回复，确保服务不中断。

4. 效果评估体系

4.1 7 维度评分标准

维度评估内容1分3分5分
相关性回复是否与问题相关完全不相关部分相关精准匹配
深度是否深入探讨核心表面敷衍有初步分析多角度深刻洞察
清晰度表达是否清晰混乱难懂基本清晰结构化、易懂
共情是否理解用户情感冷漠机械有基本共情深度情感共鸣
参与度是否积极引导对话被动结束有提问引导主动深入探索
有用性是否提供实质帮助无价值部分可用可操作性建议
流畅度对话是否自然生硬断裂基本流畅如真人对话

4.2 多模型对比评估

系统支持通过 POST /api/evaluate 接口，同时对最多 3 个模型进行 A/B 对比评估：

  1. 同一用户输入 → 并行发送至 3 个模型
  2. 收集各模型回复 → GPT-4o-mini 作为评估裁判
  3. 输出各模型在 7 维度上的评分 → 数据分析

6. 局限性与免责声明

  • 非医疗设备: DeepCalm AI 不构成诊断、治疗或医疗建议。紧急情况请拨打当地急救热线。
  • 数据有限: 效果对比基于系统内部评估，非独立第三方临床试验，p值仅供参考。
  • 模型依赖: 所有模型通过 OpenRouter 网关调用，OpenRouter 故障会影响全部 AI 功能（降级至 mock）。
  • 语言覆盖: 7 语言翻译质量依赖各模型的跨语言能力，小语种（泰语/马来语）覆盖可能存在波动。
