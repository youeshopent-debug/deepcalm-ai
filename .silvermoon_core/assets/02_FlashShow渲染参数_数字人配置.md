# DeepCalm AI — FlashShow 渲染参数 & 数字人配置

> **产出者**：蓝灵儿
> **渲染引擎**：FlashShow (闪剪) — 数字人 + 素材合成
> **数字人风格**：Tech Founder 温暖风（非商务）

---

## 一、数字人通用配置（脚本 A & B 共用）

| 参数 | 值 | 说明 |
|------|-----|------|
| **人物模型** | 女性/男性数字人（推荐女性，亲和力更高） | 保持两个脚本同一人物 |
| **景别** | 半身（腰部以上） | 画面占比约40% |
| **人物位置** | 居中偏左（右侧留空给文字/手机） | 脚本A无手机可居中 |
| **灯光方案** | 暖黄侧逆光 + 面光补光 | 色温 3200K，模拟黄昏室内光 |
| **背景** | 深色渐变虚化（#0F1420→#1A2238） | 与 DeepCalm 品牌背景色一致 |
| **服装** | 浅米色/燕麦色圆领针织衫 | 非正装，营造"睡前朋友"感 |
| **表情** | 脚本A: 温柔微笑，轻声；脚本B: 自信微笑，稍有力 |
| **眼神** | 脚本A: 直视镜头（对话感）；脚本B: 指向手机/右上（展示感） |
| **口型同步** | 自动（VO 音频驱动） | FlashShow 原生支持 |
| **渲染分辨率** | 1080×1920 @ 30fps | 竖屏短视频标准 |
| **输出格式** | MP4 H.264, 码率 8Mbps | TikTok/IG Reels 兼容 |

## 二、脚本 A 渲染配置（深夜解压氛围感 · 22s）

### 2.1 时间线分轨

```
┌─────┬─────┬─────┬──────┬──────┐
│ 0-3 │ 3-8 │ 8-13│13-18 │18-22 │
├─────┼─────┼─────┼──────┼──────┤
│ V1  │ V2  │ V3  │ V4   │ V5   │  ← 视频轨
│     │     │     │ V4-A │      │  ← 数字人轨
│  A1 │     │     │ A2   │  A1  │  ← 音频轨
└─────┴─────┴─────┴──────┴──────┘
```

### 2.2 各轨参数

| 时间 | 视频层(V) | 数字人层 | BGM | VO | 转场 |
|------|-----------|---------|-----|-----|------|
| 0-3s | V1: 雨滴窗景微距 | — | BGM-A 淡入 | — | Fade In 0.5s |
| 3-8s | V2: 播放器录屏 | — | BGM-A | VO-A1 | Cross Dissolve 0.3s |
| 8-13s | V3: 共鸣墙流星特效 | — | BGM-A 稍低 | VO-A2 | Wipe Right 0.4s |
| 13-18s | V4: 数字人半身背景 | V4-A: 数字人(暖光) | BGM-A 最低 | VO-A3 | Dip to Black → Fade In 0.3s |
| 18-22s | V5: CTA按钮动画 | — | BGM-A 渐弱 | VO-A4 | Scale Up 0.5s |

### 2.3 音轨分离

| 音轨 | 内容 | 电平 | 备注 |
|------|------|------|------|
| VO (人声) | 4段口播 | -6dB 主声轨 | 英语用自然美音，中文用标准普通话，马来文用标准马来音 |
| BGM (音乐) | Lofi Rain + Piano | -20dB (VO时段-24dB) | 自动闪避(ducking) |
| SFX (音效) | 雨声加强 | -18dB | 仅0-3s加强雨声质感 |

### 2.4 字幕配置

| 语言 | 字幕位置 | 字体 | 字号 | 颜色 |
|------|---------|------|------|------|
| 英文 | 底部安全区上方 | Inter Bold | 36px | #E8E9F3 + 黑色描边 |
| 中文 | 同上 | Noto Sans SC Bold | 36px | 同上 |
| 马来文 | 同上 | Inter Bold | 36px | 同上 |
| 3s标题 | 中央 | Inter Black | 56px | #F0F0FF + glow(1px) |

- 0-3s 标题文字：居中大号显示，3s停留→Fade Out
- 其余VO：底部字幕，跟随口播逐词或逐句出现

## 三、脚本 B 渲染配置（功能导向型 · 30s）

### 3.1 时间线分轨

```
┌─────┬─────┬──────┬──────┬──────┬──────┐
│ 0-4 │ 4-8 │ 8-15 │15-22 │22-28 │28-30 │
├─────┼─────┼──────┼──────┼──────┼──────┤
│ V1  │ V2  │ V3   │ V4   │ V5   │ V6   │  ← 视频轨
│     │     │      │      │ V5-A │      │  ← 数字人轨
│ A1  │ A2  │      │ A2   │      │      │  ← 音频轨
└─────┴─────┴──────┴──────┴──────┴──────┘
```

### 3.2 各轨参数

| 时间 | 视频层(V) | 数字人层 | BGM | VO | 转场 |
|------|-----------|---------|-----|-----|------|
| 0-4s | V1: 闹钟砸枕画面 | — | BGM-B1 低频电子音 | — | Cut 硬切 (紧张感) |
| 4-8s | V2: 睡眠周期图表 | — | BGM-B2 淡入(lo-fi) | VO-B1 | Cross Dissolve 0.3s |
| 8-15s | V3: 计算器录屏 | — | BGM-B2 | VO-B2 | Push Left 0.3s |
| 15-22s | V4: 对比动画(左右分屏) | — | BGM-B2 高潮 | VO-B3 | Wipe Center 0.4s |
| 22-28s | V5: 手机展示DeepCalm | V5-A: 数字人持手机 | BGM-B2 稍低 | VO-B4 | Cross Dissolve 0.3s |
| 28-30s | V6: 黑底白字CTA帧 | — | BGM-B2 渐弱淡出 | — | Fade Out 0.5s |

### 3.3 音轨分离

| 音轨 | 内容 | 电平 | 备注 |
|------|------|------|------|
| VO (人声) | 4段口播 | -6dB 主声轨 | 脚本B语气稍快，带讲解感 |
| BGM-B1 (前段) | 低频电子紧张音 | -15dB，4s渐出 | 制造对比反差 |
| BGM-B2 (主体) | Lo-fi Hip Hop | -20dB (VO时段-24dB) | 0-4s转BGM-B2时硬切 |
| SFX | 闹钟声(0s)、计算器提示音(14s) | -12dB | 仅2处音效 |

### 3.4 字幕配置

与脚本A一致，另加：

| 时间 | 特殊字幕 | 位置 | 字号 |
|------|---------|------|------|
| 4-8s | "REM 90min" 标注 | 图中高亮浮动 | 28px |
| 8-15s | 计算结果放大闪烁 | 录屏区域中心 | 48px |
| 15-22s | 左右对比标签"VS" | 分屏中心线 | 40px |
