# DeepCalm AI — 备用方案：数字人素材不足替代策略

> **方案等级**：Plan B（数字人渲染不可用时的降级方案）
> **制作工具**：FFmpeg + Python MoviePy + edge-tts
> **核心原则**：不依赖数字人，纯素材拼接+AI语音，保证内容完整性

---

## 评估：什么时候需要走备用方案

| 场景 | 触发条件 | 推荐方案 |
|------|---------|---------|
| FlashShow 不可用 | 闪剪服务器宕机/许可证过期 | B1 或 B2 |
| 数字人模型不匹配 | 现有模型无法表现"温暖感" | B1 |
| 渲染排队时间太长 | 6个视频预计 99min，超时降级 | B1+B2 混搭 |
| 预算限制 | 闪剪算力不够 | B1（纯离线方案） |
| 追求快速上线 | 1小时内需要发布 | B2（完全无需数字人） |

## 方案 B1：文字动画替代数字人（推荐 · 保留部分数字人）

### 适用
- 数字人素材不够（只能拍1-2段）
- FlashShow 排队但最终能用

### 策略：用文字动画 + 氛围视频填充数字人时段

#### 脚本 A 13-18s 替代方案（原数字人5s）

| 替代层级 | 画面 | 操作 |
|---------|------|------|
| 底层 | 继续播放共鸣墙/氛围视频循环 | 复用 A3 素材向后延长5s |
| 中层 | 粗体大字逐词弹出：**"Just Be Still"** / **"安静待着"** / **"Diam Je"** | 每1s弹出一个词，带淡入+轻微上移 |
| 上层 | 顶部叠加半透明玻璃质感卡片，内含完整口播文案 | 类似歌词字幕效果，但居中央 |

**动效参数（FFmpeg drawtext 实现）：**

```bash
# 逐词弹出效果（以英文为例：3行文字，每行停留1.5s）
ffmpeg -i atmosphere_bg.mp4 \
  -vf "drawtext=text='You don't have to':x=(w-tw)/2:y=h*0.35:fontsize=42:fontcolor=#E8E9F3:enable='between(t,0,1.5)':alpha=0.9,
       drawtext=text='fight tonight.':x=(w-tw)/2:y=h*0.42:fontsize=42:fontcolor=#E8E9F3:enable='between(t,1.5,3)',
       drawtext=text='Just be still.':x=(w-tw)/2:y=h*0.49:fontsize=52:fontcolor=#F0D68A:enable='between(t,3,4.5)',
       drawtext=text='DeepCalm is free. Always.':x=(w-tw)/2:y=h*0.56:fontsize=36:fontcolor=#A29BFE:enable='between(t,4.5,5)'" \
  -c:v libx264 -preset fast output_b1.mp4
```

#### 脚本 B 22-28s 替代方案（原数字人6s）

| 替代层级 | 画面 | 操作 |
|---------|------|------|
| 底层 | DeepCalm 主页录屏慢速播放/放大展示 | 复用 B3 素材，静帧或慢速 pan |
| 中层 | 3个关键句依次弹出：**"Stop guessing."** → **"Let AI do the work."** → **"DeepCalm is free."** | 每2s弹出1句，带打字机效果 |
| 上层 | 手机框选素材放大至90% | 模拟"用户正在看"的 POV |

## 方案 B2：纯录屏 + AI 语音（零数字人 · 最快上线）

### 适用
- FlashShow 完全不可用
- 需要在 30 分钟内出片
- 只靠现有网页录屏素材

### 核心替换逻辑

将数字人出镜时段全部替换为：
1. **录屏素材混剪** — 已有 DeepCalm 网站录屏循环播放
2. **AI 语音配音** — `edge-tts` 生成 VO 音轨
3. **文字覆盖** — FFmpeg drawtext 叠加核心文案

### 实施步骤

#### Step 1: 用 edge-tts 生成 VO 音轨

```bash
# 英文 VO 脚本A（数字人段）
edge-tts --voice en-US-JennyNeural \
  --text "You don't have to fight tonight. Just be still. DeepCalm is free. Always." \
  --write-media vo_a_en.mp3 \
  --write-subtitles vo_a_en.srt

# 中文 VO
edge-tts --voice zh-CN-XiaoxiaoNeural \
  --text "今晚不用战斗。安静待着就好。DeepCalm 永远免费。" \
  --write-media vo_a_zh.mp3

# 马来文 VO
edge-tts --voice ms-MY-YasminNeural \
  --text "Malam ni tak payah lawan. Diam je. DeepCalm percuma, sentiasa." \
  --write-media vo_a_ms.mp3
```

**edge-tts 推荐语音模型：**

| 语言 | 推荐语音 | 风格 |
|------|---------|------|
| 英文 | `en-US-JennyNeural` | 温暖女性 |
| 中文 | `zh-CN-XiaoxiaoNeural` | 亲切温柔 |
| 马来文 | `ms-MY-YasminNeural` | 标准马来女性 |

#### Step 2: 用 FFmpeg 合成视频

```bash
# 脚本A纯录屏版合成（以英文为例）
ffmpeg \
  -i rain_macro.mp4          `# 0-3s 雨滴素材` \
  -i player_recording.mp4    `# 3-8s 播放器录屏` \
  -i resonance_wall.mp4      `# 8-18s 共鸣墙（延长至代替数字人时段）` \
  -i vo_a_en_full.mp3        `# VO音轨` \
  -i bgm_rain.mp3            `# BGM` \
  -filter_complex " \
    [0:v]trim=0:3,setpts=PTS-STARTPTS[v1]; \
    [1:v]trim=0:5,setpts=PTS-STARTPTS[v2]; \
    [2:v]trim=0:10,setpts=PTS-STARTPTS[v3]; \
    [v1][v2][v3]concat=n=3:v=1:a=0[outv]; \
    [3:a][4:a]amix=inputs=2:duration=first[outa] \
  " \
  -map "[outv]" -map "[outa]" \
  -c:v libx264 -preset fast -crf 23 \
  -c:a aac -b:a 128k \
  deepcalm_A_EN_nodigital.mp4
```

#### Step 3: 叠加字幕（可选）

```bash
# 用 edge-tts 生成的 SRT 文件烧录字幕
ffmpeg -i deepcalm_A_EN_nodigital.mp4 \
  -vf "subtitles=vo_a_en.srt:force_style='FontName=Inter,FontSize=18,PrimaryColour=&H00F3F0E8,BorderStyle=1,Outline=1'" \
  -c:a copy \
  deepcalm_A_EN_subtitled.mp4
```

### B2 方案优势对比

| 维度 | 原方案（数字人） | B2方案（纯录屏） |
|------|----------------|-----------------|
| 制作时间 | 99min（6视频） | ~15min（6视频） |
| 成本 | FlashShow 算力 | 0（全离线） |
| 视觉吸引力 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| 信息传达 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ (不变) |
| 情感连接 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ (少了人格化) |

## 方案 B3：Canva 快速出片（零技术门槛）

### 适用
- 团队没有视频编辑人员
- 需要快速 A/B test 不同版本

### 操作流程

1. 打开 Canva → 创建 TikTok 视频 (1080×1920)
2. 上传已有素材：雨滴视频、录屏、截图
3. 使用 Canva 自带动画：
   - **文字动画**：`Animate → Typewriter`（打字机效果）
   - **页面过渡**：`Transition → Fade` / `Slide`
   - **元素**：搜索 "Glow" "Aurora" 等动效元素
4. 添加 Canva 音频库中的 "Lofi Rain" "Study Music" 标签
5. 导出 MP4，Canva Pro 可直接去水印

### 优势
- 无需代码，浏览器就能做
- 内置大量适合 DeepCalm 风格的模板（暗色/极光/氛围）
- 一人30分钟可出一版

### 劣势
- 精确到秒级的控制不如 FFmpeg
- 三语版本手动替换累（Canva 不支持批量多语言输出）

## 四、方案选择建议

| 成品质量 | 上线速度 | 推荐方案 |
|---------|---------|---------|
| 最高 | 较慢 | 主方案：FlashShow 数字人（优先尝试） |
| 较好 | 快速 | B1：文字动画 + 已有录屏，保留部分数字人 |
| 及格 | 极速 | B2：纯录屏 + edge-tts AI 语音 |
| 一般 | 最快 | B3：Canva 拖拽出片（非技术人员首选） |

**我的建议**：先跑 FlashShow 渲染批次1（脚本A英文）看看效果和质量。如果排队时间 > 30min 或效果不满意，立即切 B1 方案——用文字动画填充数字人时段，其他不动，这样6个视频最多多花20min。
